# AstrologStar32

AstrologStar32是一个优化重构版的Astrolog星盘计算程序，基于原始的Astrolog32项目进行了现代化改造。

## 特性

- 现代化的C++代码结构
- 模块化设计，便于维护和扩展
- 跨平台支持（Windows、Linux、macOS）
- 保留了与原始程序相同的命令行接口
- 使用Swiss Ephemeris进行精确的天体计算

## 编译

使用CMake进行编译：

```bash
mkdir build
cd build
cmake ..
make
```

在Windows上可以使用Visual Studio：

```bash
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A Win32
```

## 使用方法

```bash
AstrologStar32.exe 月 日 年 时间 夏令时 时区 经度 纬度 海拔高度 展示名称 地点
```

示例：
```bash
AstrologStar32.exe 3 22 2025 "12:30:00" "No" "-8:00:00" "116:23'50E" "39:54'27N" 39.00 "此时此刻" "北京, 中国"
```

## 参数说明

- 月：整数 1-12
- 日：整数 1-31
- 年：整数 1900-2100
- 时间：字符串 "时:分:秒"
- 夏令时：字符串 "是" 或 "否"
- 时区：字符串 "时:分:秒"
- 经度：字符串 "度:分:秒"
- 纬度：字符串 "度:分:秒"
- 海拔高度：浮点数
- 展示名称：字符串
- 地点：字符串

## 优化内容

1. **模块化结构**：将庞大的单文件拆分为多个模块
2. **现代化代码**：使用现代C++特性
3. **改进的可维护性**：清晰的代码结构和注释
4. **跨平台兼容性**：支持Windows、Linux和macOS
5. **保留核心功能**：保持与原始程序相同的输入输出格式和计算功能
6. **增强的错误处理**：改善参数验证和错误提示
7. **集成Swiss Ephemeris**：为精确天体计算提供支持
